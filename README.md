# Home Assistant private use

This page is the homepage and privacy policy for a personal Home Assistant setup. It is used by one person, for their own home, and is not offered to the public.

## What it does

It lets the owner's own Home Assistant installation connect to the owner's own Google Nest devices using the owner's own Google account.

## Privacy

No data is collected, stored, sold or shared with anyone by this project.

Any data that Google provides to the connection stays within the owner's own Home Assistant system. No third parties have access to it.

To ask a question, open an issue on this repository.
